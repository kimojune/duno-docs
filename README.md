# Duno 기획 문서

Duno(두노)는 취업준비생이 저녁에 그날 목표에 쓴 시간을 기록하면, 그 시간이 목표의 어느 부분을 채웠는지와 계획 대비 차이를 보여 주는 서비스다. 이 저장소는 그 기획 문서의 공개판이다. 모든 문서는 PM의 초안이며 바뀔 수 있다. 읽는 순서는 원페이저부터.

| 파일 | 내용 |
|---|---|
| duno-one-pager.md | 원페이저 기획안. 문제, 솔루션, 사용자 흐름, 비즈니스 규칙, 검증 계획, 역할 |
| duno-problem-definition.md | 문제 정의. 문장 버전 이력, 원인 가설, 영향, 해결 순서, 검증 목표 |
| duno-decisions.md | 의사결정 기록. 결정마다 날짜와 이유 한 줄. 본문의 (결정 1-7)이 가리키는 곳 |
| duno-screens-and-rules.md | 화면 명세와 동작 규칙. 원형 다이얼 규칙과 계산 예 |

읽는 법은 각 문서 첫머리에 있다. 본문의 (결정 1-7)은 duno-decisions.md의 절과 줄 번호다. (설문 2-8) 같은 괄호는 설문 원자료의 줄 번호인데, 설문 원자료(집계 수치, 자유 기입 원문)는 이 저장소에 없고 팀 안에서만 공유한다. 출처 절의 저장소 경로와 D·P 번호는 팀 내부 기록의 식별자라 여기서는 열어 볼 수 없다.
